# MyEmotions

Valheim-мод, который пишет ситуативные фразы от лица персонажа.

## Архитектура

Архитектура разделена по зонам ответственности:

- игровые детекторы определяют, что произошло в Valheim;
- `EmotionSituationHandler` получает определённую ситуацию;
- `EmotionPhraseProvider` выбирает фразу из конфигурации и подставляет контекст;
- `IChatService` отвечает только за отображение готового текста над локальным персонажем.

`EmotionSituationHandler` не знает, как именно игра определила ситуацию, и не работает с форматом конфигурации напрямую.

`MyEmotionsPlugin` — BepInEx entrypoint с `[BepInPlugin]`. При запуске BepInEx сам находит и загружает DLL. Конфигурация во время игры читается через `Paths.ConfigPath`, поэтому мод не зависит от Gale, Thunderstore или ручного расположения профиля.

Список ситуаций закреплён в коде. Фразы можно менять без перекомпиляции мода.

## Конфигурация

Настройки и фразы разделены на два файла в `BepInEx/config`:

- `emotionsConfigs.RU.json` — русский набор; шаблон: [emotionsConfigs.RU.json](emotionsConfigs.RU.json).
- `emotionsConfigs.EN.json` — английский набор; шаблон: [emotionsConfigs.EN.json](emotionsConfigs.EN.json).

Оба файла имеют одинаковую структуру: ключи внутри `Phrases` называются как значения `EmotionSituation`, каждое значение содержит массив фраз `Phrases` и `CooldownSeconds`. Проверка конфигурации выполняется при чтении файла. Отсутствующие файлы автоматически создаются из встроенных шаблонов.

При запуске мод загружает оба файла. Перед выбором каждой фразы он проверяет текущий язык Valheim: `Russian` использует RU, любой другой язык — EN. Переключение языка игры применяется без перезапуска мода и не сбрасывает таймеры кулдаунов. У каждого набора свои настройки включения и длительности кулдаунов. Имена существ и растений переводятся самой игрой на её текущий язык.

Если сохранился старый `emotionsConfigs.json`, при создании новых файлов из него переносятся русские тексты и настройки. Если в старом файле были поля `EnglishPhrases`, они переносятся в обычные `Phrases` английского файла; остальные английские фразы берутся из встроенного шаблона. Старый файл сохраняется, уже существующие RU/EN не перезаписываются. После создания новых файлов мод читает только RU/EN.

Для динамических данных используются placeholders, например `{enemy}`.

`GlobalPhraseCooldownSeconds` задаёт минимальную задержку между любыми фразами. `CooldownSeconds` задаёт задержку для конкретной ситуации. Для трёх событий котла код автоматически использует один общий таймер. Provider хранит предыдущую фразу отдельно для каждой ситуации и при наличии нескольких вариантов не выбирает её повторно.

Фразы эмоций отображаются только над персонажем и не добавляются в историю штатного игрового чата. Обычные сообщения игроков мод не изменяет.

После первого запуска параметры также регистрируются в BepInEx Configuration Manager. Русский набор использует прежние секции `General` и `Situations.*`, английский — `EN.General` и `EN.Situations.*`. В каждом наборе доступны общий флаг `Enabled`, общий кулдаун, а для каждой ситуации — собственный флаг, кулдаун и поле `Phrases`. Каждая строка является отдельной фразой, количество строк не ограничивается, пустые строки игнорируются. Сохранённые настройки BepInEx имеют приоритет над JSON и восстанавливаются при запуске; изменения в меню применяются сразу. JSON задаёт начальные значения при создании настроек BepInEx. Для игрового меню нужен установленный BepInEx Configuration Manager.

Пример настройки:

```json
{
  "GlobalPhraseCooldownSeconds": 7,
  "Phrases": {
    "FogStarted": {
      "CooldownSeconds": 90,
      "Phrases": [
        "Ни хрена не видно. Как в жопе у Тора."
      ]
    }
  }
}
```

## Сборка и установка

Путь к локальному профилю Valheim не зашит в репозиторий. Для локальной разработки он задаётся в игнорируемом файле `MyEmotions.csproj.user` или через MSBuild-свойство:

```powershell
dotnet build MyEmotionsMod.sln -p:ValheimProfilePath="C:\path\to\valheim\profile"
```

Обычная сборка создаёт DLL только внутри репозитория, в `bin/Debug/net48`:

```powershell
dotnet build MyEmotionsMod.sln
```

Профиль Valheim используется только как источник reference DLL для компиляции. Никакие файлы за пределы репозитория при сборке не копируются. BepInEx и игровые DLL не загружаются модом по абсолютному пути во время работы.

## Ситуации

Список ситуаций является частью API мода: игровые обработчики вызывают только эти значения. Добавление новой ситуации требует изменения `EmotionSituation` и этого раздела. Тексты фраз при этом менять не нужно.

### `RainStarted`

Срабатывает при начале дождя и повторяет фразу во время дождя после завершения кулдауна 120 секунд.

Контекстных переменных нет.

### `FogStarted`

Срабатывает при появлении тумана и повторяет фразу, пока туман сохраняется, после завершения кулдауна 120 секунд. Событие не зависит от того, находится ли игрок на корабле.

Контекстных переменных нет.

### `WetStarted`

Срабатывает при получении статуса сырости и повторяет фразу, пока статус сохраняется, после завершения кулдауна 120 секунд.

Кулдаун — 120 секунд. Контекстных переменных нет.

### `ColdStarted`

Срабатывает при получении статуса холода и повторяет фразу, пока статус сохраняется, после завершения кулдауна 120 секунд.

Кулдаун — 120 секунд. Контекстных переменных нет.

### `SailingStarted`

Срабатывает, когда локальный игрок начинает путешествие на корабле. Событие не зависит от погоды.

Контекстных переменных нет.

### `BoardedShip`

Срабатывает, когда игрок просто ступает на корабль. Для этого не нужно садиться за штурвал.

Контекстных переменных нет.

### `BowEquipped`

Срабатывает, когда игрок экипирует лук.

Контекстных переменных нет.

### `ArrowsDepleted`

Срабатывает, когда у игрока закончились стрелы во время использования лука. Если лук экипирован уже без стрел, событие не вызывается — сначала должны быть доступные стрелы.

Контекстных переменных нет.

### `WeaponDrawn`

Срабатывает, когда игрок достаёт оружие, кроме лука.

Контекстных переменных нет.

### `CauldronOpened`

Срабатывает при открытии или активации котла. Пока меню открыто, событие не повторяется каждый кадр. Использует общий таймер блока готовки — 14 секунд.

Контекстных переменных нет.

### `CauldronCookingStarted`

Срабатывает, когда игрок запускает изготовление предмета в меню котла. Использует общий таймер блока готовки — 14 секунд.

Контекстных переменных нет.

### `CauldronCookingFinished`

Срабатывает, когда таймер изготовления в меню котла завершается. Использует общий таймер блока готовки — 14 секунд.

Контекстных переменных нет.

### `FoodEaten`

Срабатывает после успешного употребления еды. Кулдаун по умолчанию — 7 секунд.

Контекстных переменных нет.

### `HostileCreatureAttack`

Срабатывает, когда враждебное существо атакует игрока и игра смогла определить его имя.

Доступная переменная:

- `{enemy}` — отображаемое имя атакующего существа.

### `PortalUsed`

Срабатывает после использования портала локальным игроком.

### Дополнительные ситуации

В конфигурацию также добавлены фразы для следующих ситуаций:

- `SwampEntered`, `PlainsEntered`, `MountainsEntered`, `MistlandsEntered` — переход в соответствующий биом;
- `DeathsquitoAttack` — атака deathsquito;
- `RaidStarted` — начало набега;
- `BossSummoned` — использование жертвенного предмета на камне босса;
- `PlayerDeath`, `PlayerRespawned` — смерть и возрождение игрока;
- `EncumberedStarted`, `LowHealthStarted`, `WeaponBroken`, `FallDamageTaken` — перегруз, опасно низкое здоровье, сломанное оружие и урон от падения;
- `FishingCatch`, `TreeFelled`, `TamedCreature` — улов рыбы, поваленное дерево и приручение существа;
- `RestedBuffStarted`, `RestedBuffExpired`, `ShelterEntered` — начало/окончание отдыха и вход под крышу;
- `CraftingCompleted` — завершение обычного крафта вне котла;
- `PlantHarvested`, `WildPlantGathered` — сбор выращенного и дикорастущего растения.

Для этих событий действуют указанные в соответствующем RU/EN-файле индивидуальные кулдауны, а общий кулдаун по умолчанию составляет 7 секунд.
